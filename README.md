# PMPP-EX
A collection of CUDA excerpts. The majority of these are from the practice problems in the book Programming Massively Parallel Processor. Some others are purely out of my curiosity. 

These will be sorted by their umbrella topics. Code will usually be written for and run on C++ 14, CUDA 12.3, on a Tesla T4 GPU (so it should also be runnable on recent GPUs, just that the code doesn't use some of their advanced compute capabilities).
